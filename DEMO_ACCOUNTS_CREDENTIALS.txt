 2. PRODUCTION HARDENING CHECKLIST
--------------------------------------------------------------------------------

STEP 1: Delete or Lock the Web Installer (`install.php`)
  After completing your initial database installation:
  - Verify that `installed.lock` exists in your web root.
  - For highest security on live production servers:
      rm install.php

STEP 2: File Permissions on Shared Hosting / Apache / Nginx
  - Set `config.php` file permissions:
      chmod 600 config.php   (or 644 if your web server requires read access)
  - Ensure uploads directory is writable:
      chmod 755 uploads/

STEP 3: Turn Off PHP Display Errors in `config.php`
  In production `config.php`:
      ini_set('display_errors', '0');
      error_reporting(E_ALL);

STEP 4: Remove Demo Data Before Real Student Onboarding
  - Log in as Director: director@linkpulse.edu / Admin@123
  - Open: Director Control Center -> Data Center & Purge
  - Select "Purge Demo Students, Fees & Documents" and click:
      "Execute Safe Demo Cleanup"
  - This preserves the primary Director account (`USR-DIR-001`) while safely
    removing all mock students, mock leads, and dummy fee records.

STEP 5: Updating Passwords via SQL
  To change the Director password to your own custom secure password in MySQL:
  ```sql
  UPDATE users 
  SET password = '$2y$10$...' -- Generate hash via password_hash('YourSecretPassword', PASSWORD_BCRYPT)
  WHERE email = 'director@linkpulse.edu';
  ```
  Or generate the BCrypt hash using the one-line PHP command:
  ```bash
  php -r "echo password_hash('YourStrongPasswordHere', PASSWORD_BCRYPT) . PHP_EOL;"
  ```
